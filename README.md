# Registrar Document Requests (Demo)

A simple static website for a class activity. It runs in the browser with no server or database.

## Run locally
Double-click `index.html`, or open it in any browser.

## Deploy
1. Create a GitHub repository and upload these files (or use `git push`).
2. Go to vercel.com, click **Add New > Project**, and import the repository.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
4. Click **Deploy**.

## Notes
- This is a demo. Data is saved in the browser only (localStorage) and there is no real login or password check.
- Do not use it for real student records.
- Fees and document names are sample values. Edit them at the top of `script.js`.
